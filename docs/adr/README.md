# Architecture Decision Records

Use esta pasta para decisões arquiteturais duradouras que expliquem contexto, decisão, alternativas e consequências.

Não use ADRs para instruções operacionais, listas de tarefas ou memória de execução. Crie um documento somente quando houver uma decisão real a preservar; não é necessário manter uma estrutura fixa de ADRs.
