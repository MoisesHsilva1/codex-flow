# Modelos de AGENTS.md

Modelos prontos para iniciar um projeto no Codex. Escolha o mais próximo da stack, copie para a raiz do projeto como `AGENTS.md` e substitua todos os campos `[ENTRE COLCHETES]` por fatos reais.

## Catálogo

- `base.md` — qualquer projeto ou stack não coberta.
- `react-vite-typescript.md` — SPA com React, Vite e TypeScript.
- `nextjs-typescript.md` — aplicação Next.js.
- `node-typescript-api.md` — API Node.js/TypeScript.
- `python-fastapi.md` — API Python com FastAPI.
- `java-spring-boot.md` — serviço Java com Spring Boot.
- `go-service.md` — serviço Go.
- `rust-service.md` — serviço ou CLI Rust.
- `monorepo-typescript.md` — monorepo TypeScript.

## Regras de uso

1. Prefira fatos observados no projeto a exemplos deste catálogo.
2. Remova seções que não se aplicam; não mantenha comandos fictícios.
3. Liste somente comandos que realmente existem e foram validados.
4. Não inclua secrets, tokens, valores de `.env` ou credenciais.
5. Adicione `AGENTS.md` em subdiretórios somente para regras específicas daquela área.
6. Depois de preencher, peça ao Codex para revisar o arquivo contra o repositório e apontar divergências.
